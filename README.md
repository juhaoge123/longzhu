DRAGON BALL: Sparking! ZERO 文件下载

## 解包文件

上传和校验完成后，可在 Releases 下载全部 ZIP 和 `SHA256SUMS.txt`。每个 ZIP 都可以单独打开。恢复完整的 `IoStore` 和 `Pak` 目录时，把所有 ZIP 解压到同一个目录。 [解包文件下载页](https://github.com/juhaoge123/longzhu/releases)

已安装 GitHub CLI 时，可以批量下载。

```sh
gh release download unpacked-2026-11-25 --repo juhaoge123/longzhu --pattern 'sparking-zero-unpacked-*.zip' --pattern 'SHA256SUMS.txt' --dir longzhu-unpacked
```
